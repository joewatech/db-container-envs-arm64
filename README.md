# db-container-env-arm64
Collection of docker compose yaml files to spin up local database containers in ARM64 (aarch64) environments.

>[**IMPORTANT**]<br>
> These compose files target **ARM64 (aarch64)** only and have only been tested on **macOS with Apple Silicon** (M1/M2/M3/M4). They are not verified on x86_64/amd64 hosts or other operating systems.
